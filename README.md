# React-assignment

 ⚡ Real-Time React Todo List Application (Full-Stack Assessment)

This is a modern, full-stack Todo List application built using React (Vite/Tailwind CSS) for the frontend and a Node.js/Express server with Socket.io for real-time task management.

The application allows users to create, read, update, and delete tasks, with immediate synchronization across all connected clients.

🚀 Key Features

Frontend: Built with React, Vite, and styled using Tailwind CSS.

Backend: Node.js/Express server implementing a RESTful API structure.

Real-Time Synchronization : Leverages Socket.io to instantly push task updates (creation, deletion, status changes) to all clients without requiring manual page refreshes.

CRUD Operations: Full Create, Read, Update, and Delete functionality implemented via Express API endpoints.
